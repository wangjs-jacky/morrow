# Morrow 0.3.2

The five visual presets now use a consistent set of four-character Chinese names: 静夜阅读, 浮岛夜蓝, 石墨极简, 柔雾玻璃, and 青蓝聚焦. Their descriptions identify the reading, floating shell, monochrome geometry, frosted glass, and cyan contrast that distinguish each style.

Preset IDs, saved options, colors, and layout behavior are unchanged. The new labels appear in the preview, Apply feedback, and documentation.

Validation: unit tests, TypeScript, release package inspection, and a clean macOS installation of the published archives.
