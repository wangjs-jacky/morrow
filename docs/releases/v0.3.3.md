# Morrow v0.3.3

The customization panel now opens by default, exposing line numbers, note properties, Mermaid, reading width, and accent controls without an extra click. It can still be closed and reopened.

This is a paired theme and plugin release. Re-run the installer to update a sideloaded vault; it preserves saved plugin data and backs up replaced files. Restart Obsidian after updating.

Validation: unit tests, TypeScript check, build, and browser verification of the expanded panel and existing controls.
