# Reading Studio 0.2.1

Five dark styles are easier to compare and use. The studio preview now fits the entire Mermaid example at common desktop sizes, keeps the theme choices visible, and uses larger note and sidebar text. Its controls, selected preset, accent swatches, and background follow the current style. The compact preview still uses fictional content; five screenshots captured from an isolated Obsidian vault are in [`design/packs/`](../../design/packs/).

The native theme also aligns the Minimal Graphite file highlight with its preview and colors Mermaid arrowheads and return lines with the selected style. Changing Deep Reading to violet or mint now changes its Mermaid node outlines too. Saved settings and the install layout are unchanged, so 0.2.0 configurations remain compatible.

Install both ZIP files from this release into the same vault. Follow the [setup guide](../../README.md) for Obsidian's dark mode, line-number, and property prerequisites.

Validation: unit tests, TypeScript, build and ZIP inspection, Ego Browser interaction checks at 1440×900 and 1280×800, plus application of all five styles in an isolated Obsidian 1.13.7 vault on macOS. The real note was checked for visible properties, line numbers, and Mermaid.
