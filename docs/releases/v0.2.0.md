# Reading Studio 0.2.0

Five selectable dark packs now share one native Obsidian theme: Deep Reading, Cupertino Night, Minimal Graphite, Soft Mist, and Prism Focus. Each pack changes the sidebar, note, properties, and Mermaid surfaces; line numbers, properties visibility, Mermaid styling, body width, and accent remain independent controls.

Switching packs updates the preview first. Apply persists the complete pack and options, Reset restores the current pack's defaults, and Undo restores the previous applied configuration. Existing 0.1.0 Deep Reading settings remain compatible.

This release includes the theme ZIP and companion controls-plugin ZIP. Install both into the same vault, select the Reading Studio theme and Obsidian's dark base color scheme, and enable the plugin. The [setup guide](../../README.md) and [pack inheritance notes](../theme-inspiration.md) cover details.

Verification: 24 unit tests, TypeScript type checking, Ego Browser end-to-end interaction testing, and isolated Obsidian 1.13.7 rendering on macOS. The interaction test covers five previews, Apply, reload, cross-pack Undo, Reset, and blocked prerequisites. Native checks covered properties, line numbers, Mermaid, and the distinct pack treatments.
