# Morrow v0.3.4

Morrow now checks the latest complete GitHub Release when its controls view opens. When a newer version is available, an in-app banner offers a version-pinned terminal update command. The user copies and runs the command; the plugin does not execute installers or modify itself. If clipboard access fails, the command remains selectable in the view. Version-check failures do not interrupt theme controls.

Validation: unit tests cover version comparison, copying, clipboard failure, and offline behavior. TypeScript and package checks pass. The update banner was checked in a browser; native Obsidian appearance remains unverified.
