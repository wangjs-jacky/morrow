# Morrow 0.3.1

Morrow includes one theme, one controls plugin, and five dark visual presets. The installer handles only Morrow installations and preserves their saved options on repeat runs. Soft Mist uses frosted-glass surfaces, while Prism Focus uses a quieter cyan.

Validation: 24 unit tests, TypeScript, ZIP inspection, CI, and a macOS install check using the published archives in a temporary vault with 17 other plugins. Native visual confirmation remains outstanding.
