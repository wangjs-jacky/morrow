# Morrow 0.3.0

Reading Studio is now **Morrow**. The GitHub repository, Obsidian theme, companion plugin, installer, and release archives use the new name. The five preset IDs and saved options are unchanged.

Run the [one-command installer](../../README.md) again to upgrade an existing vault. It backs up the old theme and plugin, copies saved controls into `morrow-controls`, removes the old plugin ID from the enabled list, and activates Morrow. Restart Obsidian afterward. The installer also supports repeat runs without adding duplicate plugin IDs.

Soft Mist gains frosted-glass surfaces in the native theme and preview; Prism Focus uses a quieter cyan. The previously published 0.2.x screenshots remain available as historical references and do not represent this release's exact appearance.

Validation: 24 unit tests, TypeScript, package build and ZIP inspection, plus a macOS installer migration test with an older installation and 17 other plugins. A native visual check of the renamed release remains outstanding.
